# ADR-001: Workspace and evidence boundaries

Date: 2026-10-09. Status: accepted for repository setup under the requested organization work; academic direction remains proposed.

Use Final-Thesis-Setup as the integrated code, paper, and research workspace. Copy selected source/evidence with hashes and retain the original sibling repository. This avoids rewriting historical paths while providing a self-contained timing replay and manuscript scaffold.

Use the October 5 audit to qualify historical results. Importing a file does not validate its claims. Keep manuscript metadata explicit placeholders until the team supplies details. A generic report class is provisional until the official institutional template is available.

Alternatives considered: restructuring the entire historical repository; retaining only links to sibling files. The selected approach preserves source context and makes the lightweight workflow portable. The cost is maintaining a clearly labeled source snapshot; future vendor updates need new provenance records.
